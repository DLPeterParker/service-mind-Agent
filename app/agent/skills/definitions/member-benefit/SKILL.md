## 会员权益查询流程

当用户询问会员相关问题时，按以下流程处理。

### 第一步：确认用户身份

- 查看 System Prompt 中的用户记忆上下文（UserProfile），确认会员等级
- 如果用户是普通用户（非会员），告知注册会员的方式和权益

### 第二步：查询会员权益

调用 `search_knowledge` 检索"会员权益"相关文档，根据用户等级给出：

- **普通会员**：基础权益（积分累积、专属客服）
- **黄金会员**：普通会员权益 + 每月包邮券 + 生日礼
- **钻石会员**：黄金会员权益 + 无忧退（一年4次） + 优先发货

### 第三步：针对性回答

根据用户的具体问题：
- 问积分：说明积分获取规则和兑换方式
- 问优惠券：说明当前可用的优惠券和领取方式
- 问升级：说明升级条件和当前差距

### 第四步：主动推荐

如果用户还未使用某些权益，主动提醒：
- 即将过期的优惠券
- 未使用的无忧退次数
- 积分可兑换的商品

### 注意事项

- 会员权益信息以 `search_knowledge` 检索结果为准
- 不要承诺检索结果中没有的权益
- 如果用户对权益有疑问，建议联系人工客服核实
